# Saba Deck

配信の英語を、本人の声の切り抜き音声つきで覚える、自分用の単語帳アプリ（iPhone のホーム画面に入れて使う Web アプリ）。

- 画面：このリポジトリ（GitHub Pages）。データ・音声・合言葉は入っていません。
- データ：利用者が自分で用意する Google Apps Script のウェブアプリ（スプレッドシートと Google ドライブ）に、合言葉つきで fetch します。
- 試しに見る：`?demo=1` を付けると、作り物のデータで動きます。

## 中身

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `styles.css` | 見た目（明るい「海辺」と暗い「夜の海」） |
| `app.js` | 動き。裏方には `{ key, action, args }` を POST する |
| `demo.js` | `?demo=1` のときだけ読む作り物のデータ |
| `sw.js` | 電波がないときも前回の画面を出す |
| `release.py` | 公開の前に実行（構文の確認と版の番号の書きこみ） |

公開：`python release.py` → commit → push。開いているアプリは版の違いに気づいて新しくなります。
